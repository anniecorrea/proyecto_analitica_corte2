# Evidencias generadas

Esta carpeta contiene resultados reproducibles del notebook acumulativo. No se
divide por semanas ni entregas.

- `eda/`: graficas y tablas del analisis exploratorio.
- `ventaneo_hu/`: histogramas y comparacion del ventaneo oseo.
- `datos/`: metadatos de fragmentos generados por el notebook.
- `datos_targets/`: manifiesto de cortes y bounding boxes de referencia.
- `visualizador_mesh_caso_001.html`: malla interactiva generada directamente
  por `proyecto_pengwin.ipynb`.
- Los demas HTML y PNG conservan evidencia visual historica valida del mismo
  proyecto.

Las evidencias complementan el notebook, pero el notebook es la fuente unica
del flujo ejecutable.
